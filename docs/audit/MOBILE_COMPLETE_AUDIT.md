### MOB-AUD-07 — Metapodaci APK updatera i ograničenja preuzimanja nisu runtime validirani (P3 — osnovna kodna sanacija završena)

**Dokaz i sanacija:** updater koristi `unknown` JSON, prekida metadata fetch nakon 10 sekundi, ograničava metadata veličinu, validira tipove/opsege polja i dozvoljava samo canonical APK path unutar API origin-a. Preuzimanje ima 100 MiB gornju granicu, veličinu fajla mora poklapati deklarisanu vrijednost, te zadržava SHA-256 provjeru prije instalacije. Release parser, URL resolver, timeout, veličina i hash pokriveni su updater regresijskim testovima; implementacija je dokumentovana u Sliceu 4.

**Preostala provjera:** nije testirana stvarna Android native instalacija, OS dozvole/handler niti ponašanje nad release fajlom sa servera na fizičkom uređaju. Ne instalirati testni APK iz produkcijskog toka bez dogovorenog testnog okruženja.

### MOB-AUD-09 — Greške pri otvaranju vanjskih linkova na Contact/Home (P3 — kodno sanirano u Sliceovima 25 i 41)

**Dokaz i sanacija:** Contact i Home tel/mailto/društveni linkovi prolaze kroz `tryOpenExternalUrl`, koji dozvoljava samo eksplicitne URL sheme, normalizuje destinaciju i hvata odbijeni `Linking.openURL` promise. **Preostala provjera:** OS nema-app/handler slučajevi nisu izvršeni na fizičkom uređaju; Home proširenje je Slice 41, CI run `41277422103` je prošao sva četiri joba.
